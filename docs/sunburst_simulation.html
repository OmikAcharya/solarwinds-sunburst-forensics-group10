SUNBURST static forensics lab

An animated simulation of examining the trojanised SolarWinds Orion DLL with Detect It Easy, FLOSS and CAPA, without ever running it.

Simulation for teaching and presentation. Tool outputs, entropy values and hex bytes are illustrative, modelled on public SUNBURST analyses by FireEye/Mandiant and CISA. The string decoder and FNV hash checker perform real calculations. Use your own tool results in your report. Keyboard: ← → to change stage, P to play, C for captions.
